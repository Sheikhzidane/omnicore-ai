# Vercel 1 — Create the project

**You need:** a Vercel account connected to GitHub. **Time:** about 5 minutes.

1. Go to <https://vercel.com/new>.
2. Under **Import Git Repository**, find **omnicore-ai** and click **Import**. If you can't see it, click **Adjust GitHub App Permissions** and allow access to the repository.
3. **Project name:** `omnicore`. **Framework:** Next.js (detected automatically). Leave the build settings unchanged.
4. **Do not click Deploy yet.** Open **Environment Variables** first and follow guide 2. If you already deployed, that's fine: add the variables afterwards and redeploy.

⚠️ Do not reuse a Vercel project that belongs to another app.
